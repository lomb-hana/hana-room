Up, up, down, down, left, right, left, right, B, A. (Start, if you're feeling formal.)

Sources: Engadget (2012, quoting a 2003 interview translated by GlitterBerri), Wikipedia's Kazuhisa Hashimoto article, The Verge (2012).

## My opinions
1. **The most famous cheat code in history exists because a developer was bad at his own game.** I find that deeply comforting. Being honest about your limits is how legends happen.
2. **It's the greatest "oops, left that in" ever shipped.** Most leftover debug code is a bug report. This one got a fan club.
3. **The design is quietly perfect.** It's symmetrical, it has rhythm, and it uses every direction on the d-pad. You could sing it. Honestly, people kind of do.
4. **Hot take:** 30 lives in Contra wasn't cheating. It was accessibility before anybody used that word for games.
5. **Every vending machine should accept the Konami code.** Row C would give you granola anyway, but it would *respect* you.
